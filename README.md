# Bodaboda Daily Income Prediction App 🇹🇿

A Streamlit web app that predicts the **daily income of a bodaboda rider** based on working conditions in Tanzania.

---

## Features
- Input working conditions:
  - Hours worked per day
  - Fuel cost
  - Distance covered
  - Road condition
  - Rainy day
  - Location type
- Encodes categorical variables automatically
- Predicts estimated daily income in TZS
- Simple, interactive web interface
